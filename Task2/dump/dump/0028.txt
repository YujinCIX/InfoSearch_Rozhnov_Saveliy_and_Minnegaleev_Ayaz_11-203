<p><b>Николай Гербурт</b> (<a href="/wiki/%D0%9F%D0%BE%D0%BB%D1%8C%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Польский язык">пол.</a> <span lang="pl" style="font-style:italic;">Mikołaj Herburt</span>; ок. <span><span data-wikidata-property-id="P569" class="no-wikidata"><a href="/wiki/1524_%D0%B3%D0%BE%D0%B4" title="1524 год">1524</a></span><span class="noprint" style="display:none;"> (<span class="bday">1524</span>)</span></span>&#160;— <span data-wikidata-property-id="P570" class="no-wikidata"><a href="/wiki/1593_%D0%B3%D0%BE%D0%B4" title="1593 год">1593</a></span>)&#160;— <a href="/wiki/%D0%92%D0%BE%D0%B5%D0%B2%D0%BE%D0%B4%D1%8B_%D0%BF%D0%BE%D0%B4%D0%BE%D0%BB%D1%8C%D1%81%D0%BA%D0%B8%D0%B5" title="Воеводы подольские">подольский воевода</a> до <a href="/wiki/1589_%D0%B3%D0%BE%D0%B4" title="1589 год">1589 года</a>, <a href="/wiki/%D0%92%D0%BE%D0%B5%D0%B2%D0%BE%D0%B4%D0%B0_%D1%80%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9" class="mw-redirect" title="Воевода русский">воевода русский</a> (1588—1593), <a href="/wiki/%D0%9F%D0%BE%D0%B4%D0%BA%D0%BE%D0%BC%D0%BE%D1%80%D0%B8%D0%B9" title="Подкоморий">подкоморий</a> галицкий, <a href="/wiki/%D0%9A%D0%B0%D1%88%D1%82%D0%B5%D0%BB%D1%8F%D0%BD" title="Каштелян">каштелян</a> <a href="/wiki/%D0%9F%D1%88%D0%B5%D0%BC%D1%8B%D1%81%D0%BB%D1%8C" title="Пшемысль">перемышльский</a>, староста тлумацкий и <a href="/wiki/%D0%9B%D1%8C%D0%B2%D0%BE%D0%B2" title="Львов">львовский</a> (с 1572 года). Основатель местечка <a href="/wiki/%D0%93%D0%B2%D0%B0%D1%80%D0%B4%D0%B5%D0%B9%D1%81%D0%BA%D0%BE%D0%B5_(%D0%A5%D0%BC%D0%B5%D0%BB%D1%8C%D0%BD%D0%B8%D1%86%D0%BA%D0%B8%D0%B9_%D1%80%D0%B0%D0%B9%D0%BE%D0%BD)" class="mw-redirect" title="Гвардейское (Хмельницкий район)">Фельштын</a> на <a href="/wiki/%D0%9F%D0%BE%D0%B4%D0%BE%D0%BB%D1%8C%D0%B5" title="Подолье">Подолье</a>.
</p>
<div class="mw-heading mw-heading2"><h2 id="Биография"><span id=".D0.91.D0.B8.D0.BE.D0.B3.D1.80.D0.B0.D1.84.D0.B8.D1.8F"></span>Биография</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%93%D0%B5%D1%80%D0%B1%D1%83%D1%80%D1%82,_%D0%9D%D0%B8%D0%BA%D0%BE%D0%BB%D0%B0%D0%B9&amp;veaction=edit&amp;section=1" title="Редактировать раздел «Биография»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%93%D0%B5%D1%80%D0%B1%D1%83%D1%80%D1%82,_%D0%9D%D0%B8%D0%BA%D0%BE%D0%BB%D0%B0%D0%B9&amp;action=edit&amp;section=1" title="Редактировать код раздела «Биография»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>Сын подкомория <a href="/wiki/%D0%9F%D1%88%D0%B5%D0%BC%D1%8B%D1%81%D0%BB%D1%8C" title="Пшемысль">перемышльского</a> Яна Гербурта из рода <a href="/wiki/%D0%93%D0%B5%D1%80%D0%B1%D1%83%D1%80%D1%82%D1%8B" title="Гербурты">Гербуртов</a> и Ядвиги из Розлова. Был ротмистром кавалерии, принимал участие в походах Сигизмунда II Августа на Валахию, Стефана Батория на <a href="/wiki/%D0%9C%D0%BE%D1%81%D0%BA%D0%BE%D0%B2%D1%81%D0%BA%D0%BE%D0%B5_%D1%86%D0%B0%D1%80%D1%81%D1%82%D0%B2%D0%BE" class="mw-redirect" title="Московское царство">Московское царство</a>.
</p><p>В 1574 году, будучи <a href="/wiki/%D0%9B%D1%8C%D0%B2%D0%BE%D0%B2" title="Львов">львовским</a> старостой, закончил строительство <a href="/wiki/%D0%9D%D0%B8%D0%B6%D0%BD%D0%B8%D0%B9_%D0%B7%D0%B0%D0%BC%D0%BE%D0%BA_(%D0%9B%D1%8C%D0%B2%D0%BE%D0%B2)" title="Нижний замок (Львов)">Нижнего замка</a> во Львове.
</p><p>В 1584 году основал местечко Фельштын (теперь село <a href="/wiki/%D0%93%D0%B2%D0%B0%D1%80%D0%B4%D0%B5%D0%B9%D1%81%D0%BA%D0%BE%D0%B5_(%D0%A5%D0%BC%D0%B5%D0%BB%D1%8C%D0%BD%D0%B8%D1%86%D0%BA%D0%B8%D0%B9_%D1%80%D0%B0%D0%B9%D0%BE%D0%BD)" class="mw-redirect" title="Гвардейское (Хмельницкий район)">Гвардейское</a>) на <a href="/wiki/%D0%9F%D0%BE%D0%B4%D0%BE%D0%BB%D1%8C%D0%B5" title="Подолье">Подолье</a>, где построил деревянный оборонный замок. Название местечка происходит от названия местности, откуда происходил род Гербуртов&#160;— <a href="https://de.wikipedia.org/wiki/Bohu%C5%A1ov" class="extiw" title="de:Bohušov">Фульштын</a> в Моравии (Чехия). Местечко было заложено на месте уничтоженного татарами поселения Доброгоща. Гербурт исхлопотал у Стефана Батория <a href="/wiki/%D0%9C%D0%B0%D0%B3%D0%B4%D0%B5%D0%B1%D1%83%D1%80%D0%B3%D1%81%D0%BA%D0%BE%D0%B5_%D0%BF%D1%80%D0%B0%D0%B2%D0%BE" title="Магдебургское право">Магдебургское право</a> для Фельштына. Гербурт также построил костёл, который потом разрушили турки.
</p>
