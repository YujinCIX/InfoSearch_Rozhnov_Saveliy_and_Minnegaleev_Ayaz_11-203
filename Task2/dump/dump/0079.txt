<p><b>Васи́лий Са́ввич Дрибинцев</b> (<a href="/wiki/27_%D1%84%D0%B5%D0%B2%D1%80%D0%B0%D0%BB%D1%8F" title="27 февраля">27 февраля</a> <a href="/wiki/1864" class="mw-redirect" title="1864">1864</a> — <a href="/wiki/25_%D0%B0%D0%BF%D1%80%D0%B5%D0%BB%D1%8F" title="25 апреля">25 апреля</a> <a href="/wiki/1926" class="mw-redirect" title="1926">1926</a>, <a href="/wiki/%D0%9F%D0%B0%D0%BD%D1%87%D0%B5%D0%B2%D0%BE" title="Панчево">Панчево</a>) — русский общественный деятель и политик, член <a href="/wiki/%D0%93%D0%BE%D1%81%D1%83%D0%B4%D0%B0%D1%80%D1%81%D1%82%D0%B2%D0%B5%D0%BD%D0%BD%D0%B0%D1%8F_%D0%B4%D1%83%D0%BC%D0%B0_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B9%D1%81%D0%BA%D0%BE%D0%B9_%D0%B8%D0%BC%D0%BF%D0%B5%D1%80%D0%B8%D0%B8" title="Государственная дума Российской империи">IV Государственной думы</a> от <a href="/wiki/%D0%9C%D0%BE%D0%B3%D0%B8%D0%BB%D0%B5%D0%B2%D1%81%D0%BA%D0%B0%D1%8F_%D0%B3%D1%83%D0%B1%D0%B5%D1%80%D0%BD%D0%B8%D1%8F" class="mw-redirect" title="Могилевская губерния">Могилевской губернии</a>.
</p>
<div class="mw-heading mw-heading2"><h2 id="Биография"><span id=".D0.91.D0.B8.D0.BE.D0.B3.D1.80.D0.B0.D1.84.D0.B8.D1.8F"></span>Биография</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%94%D1%80%D0%B8%D0%B1%D0%B8%D0%BD%D1%86%D0%B5%D0%B2,_%D0%92%D0%B0%D1%81%D0%B8%D0%BB%D0%B8%D0%B9_%D0%A1%D0%B0%D0%B2%D0%B2%D0%B8%D1%87&amp;veaction=edit&amp;section=1" title="Редактировать раздел «Биография»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%94%D1%80%D0%B8%D0%B1%D0%B8%D0%BD%D1%86%D0%B5%D0%B2,_%D0%92%D0%B0%D1%81%D0%B8%D0%BB%D0%B8%D0%B9_%D0%A1%D0%B0%D0%B2%D0%B2%D0%B8%D1%87&amp;action=edit&amp;section=1" title="Редактировать код раздела «Биография»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>Старообрядец-<a href="/wiki/%D0%9F%D0%BE%D0%BF%D0%BE%D0%B2%D1%86%D1%8B" title="Поповцы">поповец</a>. Из купеческой семьи, потомственный <a href="/wiki/%D0%9F%D0%BE%D1%87%D1%91%D1%82%D0%BD%D1%8B%D0%B5_%D0%B3%D1%80%D0%B0%D0%B6%D0%B4%D0%B0%D0%BD%D0%B5_(%D1%81%D0%BE%D1%81%D0%BB%D0%BE%D0%B2%D0%B8%D0%B5)" title="Почётные граждане (сословие)">почетный гражданин</a>. Землевладелец <a href="/wiki/%D0%A0%D0%BE%D0%B3%D0%B0%D1%87%D0%B5%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D1%83%D0%B5%D0%B7%D0%B4" class="mw-redirect" title="Рогачевский уезд">Рогачевского уезда</a> (4200 <a href="/wiki/%D0%94%D0%B5%D1%81%D1%8F%D1%82%D0%B8%D0%BD%D0%B0_(%D0%BC%D0%B5%D1%80%D0%B0_%D0%BF%D0%BB%D0%BE%D1%89%D0%B0%D0%B4%D0%B8)" title="Десятина (мера площади)">десятин</a>, из них 2500 при имении <a href="/wiki/%D0%94%D1%83%D1%80%D0%B0%D0%B2%D0%B8%D1%87%D0%B8_(%D0%91%D1%83%D0%B4%D0%B0-%D0%9A%D0%BE%D1%88%D0%B5%D0%BB%D1%91%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D1%80%D0%B0%D0%B9%D0%BE%D0%BD)" class="mw-redirect" title="Дуравичи (Буда-Кошелёвский район)">Дуравичи</a>).
</p><p>По окончании <a href="/wiki/%D0%9D%D0%BE%D0%B2%D0%BE%D0%B7%D1%8B%D0%B1%D0%BA%D0%BE%D0%B2" title="Новозыбков">Новозыбковского</a> <a href="/wiki/%D0%A0%D0%B5%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5_%D1%83%D1%87%D0%B8%D0%BB%D0%B8%D1%89%D0%B5" title="Реальное училище">реального училища</a> помогал отцу в торговле лесом и хлебом. В 1890 году поселился в Дуравичах, где занялся сельским хозяйством и общественной деятельностью.
</p><p>Состоял <a href="/wiki/%D0%93%D0%BB%D0%B0%D1%81%D0%BD%D1%8B%D0%B9_(%D0%BF%D0%BE%D0%BB%D0%B8%D1%82%D0%B8%D0%BA%D0%B0)" title="Гласный (политика)">гласным</a> Могилевского губернского комитета по делам земского хозяйства (с 1903), <a href="/wiki/%D0%9F%D0%BE%D1%87%D1%91%D1%82%D0%BD%D1%8B%D0%B9_%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%BE%D0%B9_%D1%81%D1%83%D0%B4%D1%8C%D1%8F" title="Почётный мировой судья">почетным мировым судьей</a> по Рогачевскому уезду (с 1904) и <a href="/wiki/%D0%93%D0%BE%D0%BC%D0%B5%D0%BB%D1%8C%D1%81%D0%BA%D0%B8%D0%B9_%D1%83%D0%B5%D0%B7%D0%B4" title="Гомельский уезд">Гомельскому уезду</a> (с 1910), почетным попечителем <a href="/wiki/%D0%A0%D0%BE%D0%B3%D0%B0%D1%87%D1%91%D0%B2_(%D0%B3%D0%BE%D1%80%D0%BE%D0%B4)" class="mw-redirect" title="Рогачёв (город)">Рогачевской</a> учительской семинарии. Был членом землеустроительной комиссии и председателем общества сельского хозяйства. В 1911 году, с <a href="/wiki/%D0%97%D0%B0%D0%BA%D0%BE%D0%BD_%D0%BE_%D0%B7%D0%B5%D0%BC%D1%81%D1%82%D0%B2%D0%B5_%D0%B2_%D0%B7%D0%B0%D0%BF%D0%B0%D0%B4%D0%BD%D1%8B%D1%85_%D0%B3%D1%83%D0%B1%D0%B5%D1%80%D0%BD%D0%B8%D1%8F%D1%85" title="Закон о земстве в западных губерниях">введением земства в Западном крае</a>, был избран председателем Рогачевской уездной <a href="/wiki/%D0%97%D0%B5%D0%BC%D1%81%D0%BA%D0%B0%D1%8F_%D1%83%D0%BF%D1%80%D0%B0%D0%B2%D0%B0" class="mw-redirect" title="Земская управа">земской управы</a> и сохранил эту должность после избрания в Думу.
</p><p>В 1912 году был избран членом <a href="/wiki/%D0%93%D0%BE%D1%81%D1%83%D0%B4%D0%B0%D1%80%D1%81%D1%82%D0%B2%D0%B5%D0%BD%D0%BD%D0%B0%D1%8F_%D0%B4%D1%83%D0%BC%D0%B0_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B9%D1%81%D0%BA%D0%BE%D0%B9_%D0%B8%D0%BC%D0%BF%D0%B5%D1%80%D0%B8%D0%B8_IV_%D1%81%D0%BE%D0%B7%D1%8B%D0%B2%D0%B0" title="Государственная дума Российской империи IV созыва">Государственной думы</a> от Могилевской губернии. Входил во фракцию <a href="/wiki/%D0%9E%D0%BA%D1%82%D1%8F%D0%B1%D1%80%D0%B8%D1%81%D1%82" class="mw-redirect" title="Октябрист">октябристов</a>, после её раскола — в группу земцев-октябристов. Входил в Совет старейшин Думы. Состоял товарищем председателя финансовой комиссии, а также членом комиссий: по народному образованию, по местному самоуправлению, по старообрядческим делам и о праздновании 300-летия дома Романовых. Был членом <a href="/wiki/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B5%D1%81%D1%81%D0%B8%D0%B2%D0%BD%D1%8B%D0%B9_%D0%B1%D0%BB%D0%BE%D0%BA" title="Прогрессивный блок">Прогрессивного блока</a>.
</p><p>В годы <a href="/wiki/%D0%9F%D0%B5%D1%80%D0%B2%D0%B0%D1%8F_%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%8F_%D0%B2%D0%BE%D0%B9%D0%BD%D0%B0" title="Первая мировая война">Первой мировой войны</a> участвовал в работе <a href="/wiki/%D0%92%D1%81%D0%B5%D1%80%D0%BE%D1%81%D1%81%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D0%B7%D0%B5%D0%BC%D1%81%D0%BA%D0%B8%D0%B9_%D1%81%D0%BE%D1%8E%D0%B7" title="Всероссийский земский союз">Всероссийского земского союза</a>. 9 марта 1917 года, после <a href="/wiki/%D0%A4%D0%B5%D0%B2%D1%80%D0%B0%D0%BB%D1%8C%D1%81%D0%BA%D0%B0%D1%8F_%D1%80%D0%B5%D0%B2%D0%BE%D0%BB%D1%8E%D1%86%D0%B8%D1%8F" title="Февральская революция">Февральской революции</a>, был назначен комиссаром <a href="/wiki/%D0%92%D1%80%D0%B5%D0%BC%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9_%D0%BA%D0%BE%D0%BC%D0%B8%D1%82%D0%B5%D1%82_%D0%93%D0%BE%D1%81%D1%83%D0%B4%D0%B0%D1%80%D1%81%D1%82%D0%B2%D0%B5%D0%BD%D0%BD%D0%BE%D0%B9_%D0%B4%D1%83%D0%BC%D1%8B" title="Временный комитет Государственной думы">Временного комитета Государственной думы</a> и Временного правительства в Могилевской губернии. 4 мая 1917 года вошел в состав Совещания для разработки плана финансового преобразования под председательством министра финансов.
</p><p>После <a href="/wiki/%D0%9E%D0%BA%D1%82%D1%8F%D0%B1%D1%80%D1%8C%D1%81%D0%BA%D0%B0%D1%8F_%D1%80%D0%B5%D0%B2%D0%BE%D0%BB%D1%8E%D1%86%D0%B8%D1%8F" title="Октябрьская революция">Октябрьской революции</a> в эмиграции в Югославии. Жил в <a href="/wiki/%D0%9F%D0%B0%D0%BD%D1%87%D0%B5%D0%B2%D0%BE" title="Панчево">Панчеве</a>.
</p><p>Скончался в 1926 году в панчевском госпитале. Был женат.
</p>
