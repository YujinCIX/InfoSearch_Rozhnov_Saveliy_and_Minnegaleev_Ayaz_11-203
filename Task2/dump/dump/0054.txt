	<h1 id="firstHeading" class="firstHeading mw-first-heading"><span class="mw-page-title-main">Темим ибн Юсуф</span></h1>
	<div id="bodyContent" class="vector-body">

		<a class="mw-jump-link" href="#searchInput">Перейти к поиску</a>
		<div id="mw-content-text" class="mw-body-content"><div class="mw-content-ltr mw-parser-output" lang="ru" dir="ltr"><p><b>Темим ибн Юсуф</b> (год рождения неизвестен&#160;— умер в <span data-wikidata-property-id="P570" class="no-wikidata"><a href="/wiki/1126_%D0%B3%D0%BE%D0%B4" title="1126 год">1126</a></span>)&#160;— сын <a href="/wiki/%D0%AD%D0%BC%D0%B8%D1%80" title="Эмир">эмира</a> <a href="/wiki/%D0%90%D0%BB%D1%8C%D0%BC%D0%BE%D1%80%D0%B0%D0%B2%D0%B8%D0%B4%D1%8B" title="Альморавиды">Альморавидов</a> <a href="/wiki/%D0%AE%D1%81%D1%83%D1%84_%D0%B8%D0%B1%D0%BD_%D0%A2%D0%B0%D1%88%D1%84%D0%B8%D0%BD" title="Юсуф ибн Ташфин">Юсуфа ибн Ташфина</a>.
</p><p>При жизни <a href="/wiki/%D0%AE%D1%81%D1%83%D1%84_%D0%B8%D0%B1%D0%BD_%D0%A2%D0%B0%D1%88%D1%84%D0%B8%D0%BD" title="Юсуф ибн Ташфин">Юсуфа</a> Темим был наместником в <a href="/wiki/%D0%92%D0%B0%D0%BB%D0%B5%D0%BD%D1%81%D0%B8%D1%8F_(%D1%82%D0%B0%D0%B9%D1%84%D0%B0)" title="Валенсия (тайфа)">Валенсии</a>, после его смерти стал наместником своего брата <a href="/wiki/%D0%AD%D0%BC%D0%B8%D1%80%D0%B0" class="mw-redirect" title="Эмира">эмира</a> <a href="/wiki/%D0%90%D0%BB%D0%B8_%D0%B8%D0%B1%D0%BD_%D0%AE%D1%81%D1%83%D1%84" title="Али ибн Юсуф">Али ибн Юсуфа</a> во всей <a href="/wiki/%D0%98%D1%81%D0%BF%D0%B0%D0%BD%D0%B8%D1%8F" title="Испания">Испании</a>, подчиненной <a href="/wiki/%D0%90%D0%BB%D1%8C%D0%BC%D0%BE%D1%80%D0%B0%D0%B2%D0%B8%D0%B4%D1%8B" title="Альморавиды">Альморавидам</a>.
</p><p>Темим в <a href="/wiki/1108_%D0%B3%D0%BE%D0%B4" title="1108 год">1108&#160;году</a> разбил кастильцев <a href="/wiki/%D0%91%D0%B8%D1%82%D0%B2%D0%B0_%D0%BF%D1%80%D0%B8_%D0%A3%D0%BA%D0%BB%D0%B5%D1%81%D0%B5" title="Битва при Уклесе">при Уклесе</a>, что дало возможность в <a href="/wiki/1110_%D0%B3%D0%BE%D0%B4" title="1110 год">1110&#160;году</a> захватить на короткий срок <a href="/wiki/%D0%A1%D0%B0%D1%80%D0%B0%D0%B3%D0%BE%D1%81%D1%81%D0%B0" class="mw-redirect" title="Сарагосса">Сарагоссу</a>.
</p>
