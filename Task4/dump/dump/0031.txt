<div class="mw-heading mw-heading2"><h2 id="Жизнеописание"><span id=".D0.96.D0.B8.D0.B7.D0.BD.D0.B5.D0.BE.D0.BF.D0.B8.D1.81.D0.B0.D0.BD.D0.B8.D0.B5"></span>Жизнеописание</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;veaction=edit&amp;section=1" title="Редактировать раздел «Жизнеописание»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;action=edit&amp;section=1" title="Редактировать код раздела «Жизнеописание»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<div class="mw-heading mw-heading3"><h3 id="Происхождение"><span id=".D0.9F.D1.80.D0.BE.D0.B8.D1.81.D1.85.D0.BE.D0.B6.D0.B4.D0.B5.D0.BD.D0.B8.D0.B5"></span>Происхождение</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;veaction=edit&amp;section=2" title="Редактировать раздел «Происхождение»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;action=edit&amp;section=2" title="Редактировать код раздела «Происхождение»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>В родословной <a href="/wiki/%D0%9B%D0%B5%D0%B2%D0%B8%D0%B9" title="Левий">Левия</a>, <a href="/wiki/%D0%90%D0%B0%D1%80%D0%BE%D0%BD" title="Аарон">Аарона</a> и <a href="/wiki/%D0%95%D0%BB%D0%B5%D0%B0%D0%B7%D0%B0%D1%80_(%D1%81%D1%8B%D0%BD_%D0%90%D0%B0%D1%80%D0%BE%D0%BD%D0%B0)" title="Елеазар (сын Аарона)">Елеазара</a>, Хелкия называется сыном <a href="/w/index.php?title=%D0%A1%D0%B5%D0%BB%D0%BB%D1%83%D0%BC_(%D0%BF%D0%B5%D1%80%D0%B2%D0%BE%D1%81%D0%B2%D1%8F%D1%89%D0%B5%D0%BD%D0%BD%D0%B8%D0%BA)&amp;action=edit&amp;redlink=1" class="new" title="Селлум (первосвященник) (страница отсутствует)">Селлума</a> (Шаллум) и отцом <a href="/wiki/%D0%90%D0%B7%D0%B0%D1%80%D0%B8%D1%8F_II" title="Азария II">Азарии</a> (<a href="/wiki/%D0%9F%D0%B0%D1%80%D0%B0%D0%BB%D0%B8%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D0%BE%D0%BD" title="Паралипоменон">1Пар.</a>&#160;<a href="https://ru.wikisource.org/wiki/%D0%9F%D0%B5%D1%80%D0%B2%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%9F%D0%B0%D1%80%D0%B0%D0%BB%D0%B8%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D0%BE%D0%BD#6:13" class="extiw" title="s:Первая книга Паралипоменон">6:13</a>; <a href="https://ru.wikisource.org/wiki/%D0%9F%D0%B5%D1%80%D0%B2%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%9F%D0%B0%D1%80%D0%B0%D0%BB%D0%B8%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D0%BE%D0%BD#9:11" class="extiw" title="s:Первая книга Паралипоменон">9:11</a><sup id="cite&#95;ref-ЭСБЕ&#124;Хелкия&#95;5-1" class="reference"><a href="#cite_note-ЭСБЕ|Хелкия-5"><span class="cite-bracket">&#91;</span>5<span class="cite-bracket">&#93;</span></a></sup>.
</p>
<div class="mw-heading mw-heading3"><h3 id="Служба"><span id=".D0.A1.D0.BB.D1.83.D0.B6.D0.B1.D0.B0"></span>Служба</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;veaction=edit&amp;section=3" title="Редактировать раздел «Служба»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A5%D0%B5%D0%BB%D0%BA%D0%B8%D1%8F&amp;action=edit&amp;section=3" title="Редактировать код раздела «Служба»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>При нём, во время предпринятого царём<sup id="cite&#95;ref-БЭАН&#124;Хелкия&#95;6-1" class="reference"><a href="#cite_note-БЭАН|Хелкия-6"><span class="cite-bracket">&#91;</span>6<span class="cite-bracket">&#93;</span></a></sup> ремонта (очищения и обновления)<sup id="cite&#95;ref-ЭСБЕ&#124;Хелкия&#95;5-2" class="reference"><a href="#cite_note-ЭСБЕ|Хелкия-5"><span class="cite-bracket">&#91;</span>5<span class="cite-bracket">&#93;</span></a></sup> <a href="/wiki/%D0%98%D0%B5%D1%80%D1%83%D1%81%D0%B0%D0%BB%D0%B8%D0%BC%D1%81%D0%BA%D0%B8%D0%B9_%D1%85%D1%80%D0%B0%D0%BC" title="Иерусалимский храм">храма</a>, был найден свиток <a href="/wiki/%D0%93%D0%B0%D0%BB%D0%B0%D1%85%D0%B0" title="Галаха">Закона</a> (Книга закона); который послужил основанием для очищения культа и коренной религиозной реформы (<a href="/wiki/%D0%9A%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A1%D0%B0%D0%BC%D1%83%D0%B8%D0%BB%D0%B0" title="Книга Самуила">2Цар.</a>&#160;<a href="https://ru.wikisource.org/wiki/%D0%92%D1%82%D0%BE%D1%80%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A6%D0%B0%D1%80%D1%81%D1%82%D0%B2#22:3" class="extiw" title="s:Вторая книга Царств">22:3</a> и сл.)<sup id="cite&#95;ref-ЕЭБЕ&#124;Хилкия&#95;4-1" class="reference"><a href="#cite_note-ЕЭБЕ|Хилкия-4"><span class="cite-bracket">&#91;</span>4<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Вместе с другими был послан <a href="/wiki/%D0%98%D0%BE%D1%81%D0%B8%D1%8F" title="Иосия">царём</a> к пророчице <a href="/wiki/%D0%9E%D0%BB%D0%B4%D0%B0%D0%BC%D0%B0" title="Олдама">Олдаме</a> (Хулде), чтобы вопросить Бога о своей судьбе и о судьбе своего народа, узнать, сбудутся ли грозные предсказания найденной Божественной книги ο <a href="/wiki/%D0%93%D0%BD%D0%B5%D0%B2_%D0%91%D0%BE%D0%B6%D0%B8%D0%B9" class="mw-redirect" title="Гнев Божий">каре Божией</a>, которая постигнет народ за неисполнение содержавшихся в ней <a href="/wiki/613_%D0%B7%D0%B0%D0%BF%D0%BE%D0%B2%D0%B5%D0%B4%D0%B5%D0%B9" title="613 заповедей">религиозных заповедей</a> (<a href="/wiki/%D0%A7%D0%B5%D1%82%D0%B2%D1%91%D1%80%D1%82%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A6%D0%B0%D1%80%D1%81%D1%82%D0%B2" title="Четвёртая книга Царств">4Цар.</a>&#160;<a href="https://ru.wikisource.org/wiki/%D0%A7%D0%B5%D1%82%D0%B2%D1%91%D1%80%D1%82%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A6%D0%B0%D1%80%D1%81%D1%82%D0%B2#22:8" class="extiw" title="s:Четвёртая книга Царств">22:8—20</a>; <a href="/wiki/%D0%9F%D0%B0%D1%80%D0%B0%D0%BB%D0%B8%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D0%BE%D0%BD" title="Паралипоменон">2Пар.</a>&#160;<a href="https://ru.wikisource.org/wiki/%D0%92%D1%82%D0%BE%D1%80%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%9F%D0%B0%D1%80%D0%B0%D0%BB%D0%B8%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D0%BE%D0%BD#34:14" class="extiw" title="s:Вторая книга Паралипоменон">34:14—28</a>; <a href="/wiki/%D0%9A%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A1%D0%B0%D0%BC%D1%83%D0%B8%D0%BB%D0%B0" title="Книга Самуила">2Цар.</a>&#160;<a href="https://ru.wikisource.org/wiki/%D0%92%D1%82%D0%BE%D1%80%D0%B0%D1%8F_%D0%BA%D0%BD%D0%B8%D0%B3%D0%B0_%D0%A6%D0%B0%D1%80%D1%81%D1%82%D0%B2#22:12" class="extiw" title="s:Вторая книга Царств">22:12</a> и сл.)<sup id="cite&#95;ref-ЭСБЕ&#124;Хелкия&#95;5-3" class="reference"><a href="#cite_note-ЭСБЕ|Хелкия-5"><span class="cite-bracket">&#91;</span>5<span class="cite-bracket">&#93;</span></a></sup><sup id="cite&#95;ref-ЕЭБЕ&#124;Хилкия&#95;4-2" class="reference"><a href="#cite_note-ЕЭБЕ|Хилкия-4"><span class="cite-bracket">&#91;</span>4<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Ему было повелено извергнуть из Храма все предметы <a href="/wiki/%D0%98%D0%B4%D0%BE%D0%BB%D0%BE%D0%BF%D0%BE%D0%BA%D0%BB%D0%BE%D0%BD%D1%81%D1%82%D0%B2%D0%BE" title="Идолопоклонство">идолослужения</a>, которые были сожжены в <a href="/wiki/%D0%9A%D0%B5%D0%B4%D1%80%D0%BE%D0%BD%D1%81%D0%BA%D0%B0%D1%8F_%D0%B4%D0%BE%D0%BB%D0%B8%D0%BD%D0%B0" title="Кедронская долина">долине Кидронской</a>, за Иерусалимом (4 Цар.
