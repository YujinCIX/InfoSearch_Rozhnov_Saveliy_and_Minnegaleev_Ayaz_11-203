<p><b>Коньки</b>&#160;— река в <a href="/wiki/%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D1%8F" title="Россия">России</a>, протекает по территории <a href="/wiki/%D0%97%D0%B0%D0%B2%D1%8C%D1%8F%D0%BB%D0%BE%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D1%80%D0%B0%D0%B9%D0%BE%D0%BD_(%D0%A3%D0%B4%D0%BC%D1%83%D1%80%D1%82%D0%B8%D1%8F)" title="Завьяловский район (Удмуртия)">Завьяловского</a> и <a href="/wiki/%D0%A1%D0%B0%D1%80%D0%B0%D0%BF%D1%83%D0%BB%D1%8C%D1%81%D0%BA%D0%B8%D0%B9_%D1%80%D0%B0%D0%B9%D0%BE%D0%BD" title="Сарапульский район">Сарапульского</a> районов <a href="/wiki/%D0%A3%D0%B4%D0%BC%D1%83%D1%80%D1%82%D0%B8%D1%8F" title="Удмуртия">Удмуртии</a>. Устье реки находится в 18&#160;км по правому берегу реки <a href="/wiki/%D0%9D%D0%B5%D1%87%D0%BA%D0%B8%D0%BD%D0%BA%D0%B0" title="Нечкинка">Нечкинка</a>. Длина реки составляет 14 км<sup id="cite&#95;ref-ГВР&#95;2-0" class="reference"><a href="#cite_note-ГВР-2"><span class="cite-bracket">&#91;</span>2<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>На её берегах расположены деревни <a href="/wiki/%D0%9A%D0%BE%D0%BD%D1%8C%D0%BA%D0%B8_(%D0%A3%D0%B4%D0%BC%D1%83%D1%80%D1%82%D0%B8%D1%8F)" title="Коньки (Удмуртия)">Коньки</a>, <a href="/w/index.php?title=%D0%97%D0%B0%D1%80%D1%8F_(%D0%A3%D0%B4%D0%BC%D1%83%D1%80%D1%82%D0%B8%D1%8F)&amp;action=edit&amp;redlink=1" class="new" title="Заря (Удмуртия) (страница отсутствует)">Заря</a>.
</p>
<div class="mw-heading mw-heading2"><h2 id="Данные_водного_реестра"><span id=".D0.94.D0.B0.D0.BD.D0.BD.D1.8B.D0.B5_.D0.B2.D0.BE.D0.B4.D0.BD.D0.BE.D0.B3.D0.BE_.D1.80.D0.B5.D0.B5.D1.81.D1.82.D1.80.D0.B0"></span>Данные водного реестра</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%9A%D0%BE%D0%BD%D1%8C%D0%BA%D0%B8_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9D%D0%B5%D1%87%D0%BA%D0%B8%D0%BD%D0%BA%D0%B8)&amp;veaction=edit&amp;section=1" title="Редактировать раздел «Данные водного реестра»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%9A%D0%BE%D0%BD%D1%8C%D0%BA%D0%B8_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9D%D0%B5%D1%87%D0%BA%D0%B8%D0%BD%D0%BA%D0%B8)&amp;action=edit&amp;section=1" title="Редактировать код раздела «Данные водного реестра»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>По данным <a href="/wiki/%D0%93%D0%BE%D1%81%D1%83%D0%B4%D0%B0%D1%80%D1%81%D1%82%D0%B2%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9_%D0%B2%D0%BE%D0%B4%D0%BD%D1%8B%D0%B9_%D1%80%D0%B5%D0%B5%D1%81%D1%82%D1%80" title="Государственный водный реестр">государственного водного реестра России</a> относится к <a href="/wiki/%D0%9A%D0%B0%D0%BC%D1%81%D0%BA%D0%B8%D0%B9_%D0%B1%D0%B0%D1%81%D1%81%D0%B5%D0%B9%D0%BD%D0%BE%D0%B2%D1%8B%D0%B9_%D0%BE%D0%BA%D1%80%D1%83%D0%B3" title="Камский бассейновый округ">Камскому бассейновому округу</a>, водохозяйственный участок реки&#160;— <a href="/wiki/%D0%9A%D0%B0%D0%BC%D0%B0" title="Кама">Кама</a> от <a href="/wiki/%D0%92%D0%BE%D1%82%D0%BA%D0%B8%D0%BD%D1%81%D0%BA%D0%B0%D1%8F_%D0%93%D0%AD%D0%A1" title="Воткинская ГЭС">Воткинского гидроузла</a> до <a href="/wiki/%D0%9D%D0%B8%D0%B6%D0%BD%D0%B5%D0%BA%D0%B0%D0%BC%D1%81%D0%BA%D0%B0%D1%8F_%D0%93%D0%AD%D0%A1" title="Нижнекамская ГЭС">Нижнекамского гидроузла</a>, без рек <a href="/wiki/%D0%91%D1%83%D0%B9_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9A%D0%B0%D0%BC%D1%8B)" title="Буй (приток Камы)">Буй</a> (от истока до <a href="/wiki/%D0%9A%D0%B0%D1%80%D0%BC%D0%B0%D0%BD%D0%BE%D0%B2%D1%81%D0%BA%D0%BE%D0%B5_%D0%B2%D0%BE%D0%B4%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B8%D0%BB%D0%B8%D1%89%D0%B5" title="Кармановское водохранилище">Кармановского гидроузла</a>), <a href="/wiki/%D0%98%D0%B6_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9A%D0%B0%D0%BC%D1%8B)" title="Иж (приток Камы)">Иж</a>, <a href="/wiki/%D0%98%D0%BA_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9A%D0%B0%D0%BC%D1%8B)" title="Ик (приток Камы)">Ик</a> и <a href="/wiki/%D0%91%D0%B5%D0%BB%D0%B0%D1%8F_(%D0%BF%D1%80%D0%B8%D1%82%D0%BE%D0%BA_%D0%9A%D0%B0%D0%BC%D1%8B)" title="Белая (приток Камы)">Белая</a>, речной подбассейн реки&#160;— бассейны притоков <a href="/wiki/%D0%9A%D0%B0%D0%BC%D0%B0" title="Кама">Камы</a> до впадения Белой. Речной бассейн реки&#160;— Кама<sup id="cite&#95;ref-ГВР&#95;2-1" class="reference"><a href="#cite_note-ГВР-2"><span class="cite-bracket">&#91;</span>2<span class="cite-bracket">&#93;</span></a></sup>.
