# Задание 5 — Разработать поисковую систему на основе векторного поиска по построенному индексу

## Описание
Описание проекта

Проект реализует векторный поиск по текстовым документам с использованием модели TF-IDF (Term Frequency – Inverse Document Frequency). Он позволяет находить наиболее релевантные документы для заданного запроса, оценивая важность слов в каждом документе и вычисляя сходство между запросом и текстами.

Проект может использоваться для создания простого поискового движка для документов, новостных статей, учебных материалов и других текстовых данных.

Функциональность
Подсчёт TF-IDF для терминов и лемм в документах.
Лемматизация текста с помощью pymorphy3 (опционально pymorphy2 в fallback).
Поиск по запросу: получение релевантных документов на основе косинусного сходства TF-IDF векторов.
Поддержка различных форм слов через лемматизацию для улучшения качества поиска.
